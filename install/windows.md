# Play {{title}} on Windows

1. Unzip **{{file}}** (right-click it, then **Extract All…**).
2. Open the **Bouncy Blobs** folder and double-click **Bouncy Blobs.exe**.
3. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The game isn't signed with a Microsoft certificate yet.

Keep the whole folder together: the game needs the `assets` folder and `steam_api64.dll` beside the exe. To uninstall, delete the folder.

**Friends can join from their phones:** in the game, choose **Party → Host**, then scan the QR code, or open bouncy-blobs.partii.games and enter the room code. No app needed.
