# Play {{title}} on Linux

1. Unzip it: `unzip "{{file}}"`
2. Run it: `cd "Bouncy Blobs" && ./"Bouncy Blobs"` (or double-click **Bouncy Blobs** in your file manager).
3. If it won't start, make it executable: `chmod +x "Bouncy Blobs"`

Keep the whole folder together: the game needs the `assets` folder and `libsteam_api.so` beside it. It needs a 64-bit distro with glibc 2.30 or newer and Vulkan graphics drivers. To uninstall, delete the folder.

**Friends can join from their phones:** in the game, choose **Party → Host**, then scan the QR code, or open bouncy-blobs.partii.games and enter the room code. No app needed.
