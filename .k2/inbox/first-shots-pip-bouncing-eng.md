# First shots — Pip bouncing — eng

Do not record until your Bevy capture mode is in. Do not use the web game. Do not edit the web level files. Do not film `partii-v1`.

When the capture mode works, record these and send the how-to with the files.

- Pip bouncing around. Several takes, about 10 seconds each.
- One set in each biome that actually runs. If a biome does not run, skip it and name it.
- Clean screen. No HUD, no tips, no run clock. The game fills the frame. No black bars.
- 1080×1920, and 1920×1080 if the mode can do both. 60 frames a second, real time, not stills.
- Game audio on if the mode records it.

Do not make crushers, fan blades, or a death the subject. A spike in the background is fine only if Pip is just bouncing.

Put the files in `content/productions/bouncy-blobs/_pool/pip-bounce/` with a NOTES.md: clip, biome, and the commit you recorded. Leave the old do-not-use folders alone.
