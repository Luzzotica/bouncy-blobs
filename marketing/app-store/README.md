# App Store / Play assets

Generated by `app-store-assets` skill.

## Upload checklist

### App Store Connect
- [ ] **App Icon** → `icon-1024.png` (1024×1024, no alpha)
- [ ] **iPhone 6.9"** screenshots → `screenshots/iphone-6.9/`
- [ ] **iPhone 6.7"** → `screenshots/iphone-6.7/` (optional if 6.9 present, still useful)
- [ ] **iPad 13"** → `screenshots/ipad-13/` (if iPad supported)

### Google Play
- [ ] **Hi-res icon** → `icon-512.png`
- [ ] **Feature graphic** → `play/feature-graphic.png`
- [ ] **Phone screenshots** → `play/phone/`

### Binary icons
Regenerated into `src-tauri/icons/` via `tauri icon` (unless `--skip-tauri-icon`).
Rebuild the iOS/Android app after regenerating.
